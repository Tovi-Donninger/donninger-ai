DONNINGER.AI — WEBSITE FOUNDATION (STEP 1)

What's included
- Responsive single-page website for desktop, tablet and mobile
- Donninger.AI brand header and navigation
- Modern mixed light/dark design with navy, white and teal accents
- Approved tagline: Build smarter. Operate better. Grow faster.
- Three platform divisions and their initial service descriptions
- How-it-works section
- Entry points for the two planned free assessments
- Mobile navigation and assessment-stage notification

How to preview
1. Extract this ZIP file.
2. Open index.html in a modern browser (Microsoft Edge, Chrome, Firefox or Safari).
3. An internet connection is needed for the optional Google Fonts import. The site otherwise uses local HTML, CSS and JavaScript.

How to publish for free (Cloudflare Pages)
1. Create a GitHub repository and upload index.html, styles.css, script.js and this README.
2. In Cloudflare, open Workers & Pages > Create > Pages > Connect to Git.
3. Select the repository.
4. Choose no framework / static HTML. Leave build command empty. Set the output directory to / (or the repository root, depending on the setup screen).
5. Deploy. Cloudflare will provide a free pages.dev preview address.

Important current limitations
- This is the Step 1 website foundation, not the complete platform.
- The assessment buttons currently explain that the questionnaires are coming in later steps; they do not collect or store customer information yet.
- No AI API, database, authentication, payments, customer dashboard or live automation integrations are connected.
- No paid services are required to preview this site locally.
